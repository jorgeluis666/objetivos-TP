    Usuarios y Claves

    Directorio de quién tiene acceso al tablero. El tablero se abre con una sola clave compartida que nunca se guarda aquí: esta lista solo registra a quién se le entregó. Se edita como borrador en este navegador hasta exportar el archivo para publicarlo.

    Cómo dar acceso o cambiar la clave
    1. Dar acceso: agrega a la persona en esta lista, exporta el archivo y publícalo. Después compártele la clave por un canal privado, nunca en el mismo mensaje que el enlace.
    2. La clave es una sola para todos y vive en el secret TP_PAGE_PASSWORD de GitHub: no está en esta lista ni en el HTML publicado.
    3. Cambiarla: GitHub > Settings > Secrets and variables > Actions > editar TP_PAGE_PASSWORD (larga y aleatoria, 16 caracteres o más) y luego Actions > "Publicar en GitHub Pages" > Run workflow.
    4. Quitar acceso: marca a la persona como Suspendida y cambia la clave, porque es compartida; luego pásale la nueva al resto.
